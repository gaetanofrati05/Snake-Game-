<h1>Snake Game</h1>

<p>
  This project is a classic Snake game written in <strong>Java</strong>. 
  The project is structured into four main classes to keep the code organized and modular.
</p>

<hr />

<h2>Project Structure</h2>

<ul>
  <li>
    <strong>GamePanel:</strong> This class creates the game panel and manages the main game loop. 
    The tile size and other settings are standardized, but you can easily modify them to adapt the panel to your preferences.
  </li>
  <li>
    <strong>KeyListener:</strong> Handles the keyboard inputs to control the snake's direction.
  </li>
  <li>
    <strong>Snake:</strong> Contains the core logic for the snake, including methods for movement and growing.
  </li>
  <li>
    <strong>Food/Tile Generator:</strong> Generates random tiles (food) on the panel for the snake to eat.
  </li>
</ul>
